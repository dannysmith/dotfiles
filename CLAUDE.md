# Danny's dotfiles

Personal dotfiles, symlinked into `$HOME` with [rcm](http://thoughtbot.github.io/rcm/rcm.7.html) (`lsrc` to dry-run, `rcup` to apply).

`claude/settings.json` and `claude/CLAUDE.md` are the live global Claude Code config — `~/.claude/settings.json` and `~/.claude/CLAUDE.md` are symlinks to them, so an edit here changes every session on this machine straight away, including this one.

**This repo is public** (github.com/dannysmith/dotfiles). Only this repo's own work belongs in a commit here: nothing personal or private, and nothing ported in from another repo or from somewhere else on this machine. Secrets never, regardless.
